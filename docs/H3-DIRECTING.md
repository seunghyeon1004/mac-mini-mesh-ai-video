# H3 디렉팅 노트 (실측으로 확인한 것만)

ai-camera-shots 스킬 규칙 + H3 실제 결과로 검증. 새 결과 나오면 맨 위에 추가.

## 잘 먹히는 것
- 고정 카메라 + 피사체 이동 방향 지정("static, locked-off ... boat crosses left to right") → 카메라 완전 고정, 배만 이동 (harbor 5)
- 이어받기(--first-frame) + "rises straight up like a crane ... ending looking straight down" → 이음새 끊김 없이 수면 높이→정수리 탑다운까지 크레인 상승 완벽 (harbor 4)
- 카메라 움직임 1개 + 속도 + 끝나는 지점 명시 → 전진·하강(드론), 고정, 사이드 트래킹 정확히 수행 (2026-11-13 harbor 1·2·3)
- 샷 표현을 문장 맨 앞에 (Aerial wide shot / Low-angle close-up / Medium wide shot at water level)
- H3 구조화 형식: integrated_multimodal_description / overall_soundscape / non_diegetic_music 한 줄씩
- 조명·대기 묘사(blue-hour, mist, lantern lights)는 거의 그대로 나옴

## 피할 것
- 5초 안에 '화면 밖 새 장소 공개'(pull back to reveal the whole village) → 공개는 되지만 중간에 장소가 녹듯 바뀌고 집들이 뭉개짐. 공개할 대상이 첫 프레임에 이미 일부 보이게 시작하거나, 공개 샷은 하드컷으로 새로 시작 (harbor 6)
- 렌즈 이름("on a 35mm lens") → 화면 속 렌즈 물건으로 그림. 대신 "shallow depth of field, soft background" 같은 화면 묘사로 (harbor 2)
- 한 클립에 연속 동작 2단계("풀린다 → 물에 빠진다") → 첫 단계에서 멈춤. 클립당 동작 1개 (harbor 2)
- "화면 정중앙에서 끝남" 같은 구도 목표는 대략만 맞음 (harbor 1)
